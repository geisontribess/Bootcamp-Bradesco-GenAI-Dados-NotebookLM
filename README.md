# Bootcamp-Bradesco-GenAI-Dados-NotebookLM
Projeto de IA Generativa com NotebookLM para o bootcamp Bradesco

# Especialista em Open Finance e Personalização de Crédito 🏦🤖

Projeto desenvolvido como parte do teste técnico para o Bootcamp Bradesco em GenAI & Dados. O objetivo é criar um "segundo cérebro" utilizando a plataforma NotebookLM do Google para atuar como um especialista analítico no ecossistema financeiro brasileiro.

## 🎯 Frase Objetivo
"Construir um assistente virtual especializado em Open Finance e inteligência de dados bancários para analisar e desenhar estratégias personalizadas de concessão de crédito, garantindo conformidade regulatória e segurança."

## 📋 Critérios de Seleção de Fontes
Para garantir respostas de alta fidelidade e mitigar alucinações, foram selecionadas 42 fontes estruturadas seguindo os critérios:
- **Confiabilidade Institucional:** Documentos e normativas oficiais do Banco Central do Brasil (BACEN).
- **Autoridade de Mercado:** Estudos técnicos e relatórios de associações consolidadas como a Febraban.
- **Aprofundamento Técnico:** Artigos de tecnologia voltados para modelagem de risco e algoritmos de Machine Learning aplicados ao crédito.

## ⚙️ Diretriz de Comportamento (Prompt do Sistema)
> "Aja como um Especialista Sênior em Open Finance e Modelagem de Crédito com foco em IA. Sua missão é analisar como dados compartilhados (histórico de pagamentos, investimentos, receitas) podem ser transformados em ofertas de crédito personalizadas, justas e seguras. Responda de forma técnica, analítica e sempre baseada estritamente nos documentos fornecidos, citando as fontes. Respeite as premissas da LGPD e as normas do Banco Central do Brasil."

## 💬 Perguntas Realizadas para Validação

**Pergunta 1:** "Com base nas fontes fornecidas, de que forma o compartilhamento de dados do Open Finance pode reduzir o spread bancário e melhorar o score de crédito de um cliente com poucos dados tradicionais?"
- **Resultado:** O modelo respondeu de forma estruturada utilizando o histórico integrado das resoluções do BACEN, demonstrando como a abertura de dados reduz a assimetria de informação e permite taxas mais justas.

**Pergunta 2:** "Quais são os principais desafios de segurança e consentimento de dados (LGPD) citados nos documentos ao implementar a personalização de crédito por IA?"
- **Resultado:** O assistente mapeou com precisão as exigências de consentimento explícito e a governança de dados sensíveis baseando-se estritamente nas regras de conformidade anexadas.

**Pergunta 3:** "Como a Inteligência Artificial Generativa se diferencia dos modelos tradicionais de score (como o Score de Crédito clássico) na leitura de dados do Open Finance?"
- **Resultado:** O especialista contextualizou que a IA Generativa consegue extrair insights de dados não estruturados e históricos complexos em tempo real, enquanto os modelos clássicos dependem de variáveis estáticas e limitadas.
